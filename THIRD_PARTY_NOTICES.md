## affectUI

`apps/web/components/ui/tool-call-card.tsx` and `thinking-loader.tsx` adapt the free
Tool Call Card (Clean) and Thinking Loader (Clean) components from
[affectUI](https://github.com/flohoeller/affectui), retrieved on 2026-10-19 from
https://www.affectui.com/r/tool-call-card-clean.json and
https://www.affectui.com/r/thinking-loader-clean.json.

The adaptations use Code Factory theme tokens, existing controls, localized copy,
and real Agent Run/trace state. No Pro component source is included.
